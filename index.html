Salvataggio su GitHub

Il token resta solo in questo browser, mai nel repository. Crealo su GitHub → Settings → Developer settings → Fine-grained tokens, limitato a questo repository con permesso Contents: Read and write. Non usarlo su dispositivi condivisi.
